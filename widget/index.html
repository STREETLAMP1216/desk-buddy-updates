책상 친구 위젯 설명서

아이폰 홈 화면·잠금 화면에 오늘 할 일과 캐릭터를 띄우고, 일정·알람 알림을 받는 방법이에요.

준비받기처음 실행홈 화면에 놓기꾸미기잠금 화면알림업데이트자주 묻는 것

0준비할 것

· 아이폰 (iOS 16 이상이면 잠금 화면 위젯까지)
· Scriptable 앱 — 무료, 앱 스토어에서 받아요
· 연동 코드 16자리 — PC 책상 친구 설정 › 폰 연동 또는 폰 앱 설정 › PC 연동에 있어요

Scriptable 받기 (App Store)

안드로이드(갤럭시)는 Scriptable이 없어서 이 위젯은 못 써요. 폰 앱(웹앱)은 그대로 쓸 수 있어요.

1스크립트 받기

위젯은 Scriptable 안에서 돌아가는 짧은 프로그램(스크립트)이에요. 이 페이지를 아이폰 Safari로 열어서 아래 순서대로 해요.

  1. 아래 스크립트 복사 버튼을 눌러요.
    파일로 받기
  2. Scriptable을 열고 오른쪽 위 + 를 눌러요.
  3. 빈 화면을 한 번 누르고 붙여넣기.
  4. 맨 위 제목(Untitled Script)을 눌러 이름을 책상 친구로 바꾸고 Done.

복사가 안 되면 스크립트 내용 보기를 열고 전체 선택 › 복사해도 돼요.

2처음 실행 — 연동 코드 넣기

  1. Scriptable 목록에서 책상 친구를 눌러 실행해요.
  2. "연동 코드"를 물어보면 16자리를 넣고 저장. 대시(-)는 있어도 없어도 돼요.
  3. 메뉴가 뜨면 미리보기 · 중간으로 잘 보이는지 확인.
  4. 알림을 허용할지 물으면 허용 — 그래야 일정·알람 알림이 와요.

코드는 아이폰 키체인에 저장돼서, 스크립트를 새 버전으로 바꿔도 다시 넣을 필요가 없어요.

3홈 화면에 놓기

  1. 홈 화면 빈 곳을 길게 눌러요 (아이콘이 흔들릴 때까지).
  2. 왼쪽 위 편집 › 위젯 추가 (또는 +).
  3. Scriptable을 찾아 크기를 골라요 — 작게 · 중간 · 크게.
  4. 놓은 위젯을 길게 눌러 위젯 편집 › Script를 책상 친구로.
  5. 이제 위젯을 누르면 책상 친구 폰 앱이 열려요.

4꾸미기 — 보여줄 칸 고르기

PC 캐릭터 옆 카드처럼, 위젯에 보여줄 칸을 골라 조합할 수 있어요. 위젯을 길게 눌러 위젯 편집 › Parameter 칸에 이름을 쉼표로 적으면 끝. 비워 두면 크기에 맞는 기본 조합이 나와요. 위젯마다 다르게 해도 돼요.

제일 쉬운 방법

Scriptable에서 책상 친구를 실행 › 위젯 꾸미기 › 칸을 위에서부터 순서대로 고르기 › 다 골랐어. 미리보기를 보여주고 조합 글자를 복사해 줘요. 그걸 Parameter에 붙여 넣으면 돼요.

5잠금 화면 위젯

  1. 잠금 화면을 길게 눌러 사용자화 › 잠금 화면.
  2. 시계 아래 위젯 칸(또는 시계 위 한 줄 칸)을 눌러 Scriptable을 골라요.
  3. 놓은 위젯을 눌러 Script를 책상 친구로.

네모 위젯 Parameter에 일정을 적으면 다음 일정이 맨 위에 와요.

6알림

위젯이 새로고침될 때마다 아래 알림을 폰에 미리 예약해 둬요. 책상 친구 앱을 닫아 둬도 와요.

· 일정 10분 전 — 오늘·내일의 시간 있는 일정 ○
· 알람 — PC나 폰 앱에서 맞춘 알람 (매일 반복도)

위젯이 홈 화면에 하나라도 있어야 예약이 계속 갱신돼요. 방금 PC에서 만든 일정은 위젯이 다음에 새로고침될 때 예약돼요 — 바로 하고 싶으면 Scriptable에서 한 번 실행해요.

7업데이트

새 버전이 나오면 1번처럼 복사해서, Scriptable의 책상 친구를 열고 전체 선택 › 붙여넣기로 덮어쓰면 돼요. 연동 코드와 위젯 설정(Parameter)은 그대로 남아요.

?자주 묻는 것

위젯이 바로 안 바뀌어요

위젯을 언제 새로 그릴지는 iOS가 정해요 (보통 15분~1시간). 바로 보고 싶으면 위젯을 눌러 책상 친구 앱을 열거나, Scriptable에서 한 번 실행하면 돼요.

시각 앞에 ⚠ 가 붙어 있어요

인터넷이 안 돼서 마지막으로 받아 둔 내용을 보여주는 중이에요. 연결되면 다음 새로고침 때 사라져요.

"연동 코드를 넣어 주세요"만 떠요

Scriptable 앱 안에서 책상 친구를 한 번 실행해 코드를 넣어야 해요 (2번).

"저장된 게 없어요"라고 떠요

그 코드로 아직 아무것도 올라간 적이 없다는 뜻이에요. PC 설정 › 폰 연동에서 코드를 만들고, 위젯에도 같은 코드를 넣었는지 확인해요.

코드를 바꾸고 싶어요

Scriptable에서 책상 친구 실행 › 코드 바꾸기.

내 할 일이 서버에 그대로 남나요?

아니요. PC·폰 앱이 연동 코드로 암호화해서 올리고, 위젯도 같은 코드로 풀어서 보여줘요. 서버에는 알아볼 수 없는 내용만 있어요. 코드는 다른 사람에게 알려주지 마세요.

캐릭터·언어를 바꾸고 싶어요

PC나 폰 앱 설정에서 바꾸면 위젯도 따라가요 (한국어·English·日本語).
